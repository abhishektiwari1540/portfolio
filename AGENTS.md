# Project Guidelines

## Portfolio Project — Abhishek Tiwari
Full-stack developer portfolio site built with React, TypeScript, GSAP, and Tailwind CSS.

### Structure
- `src/components/site/` — Shell, navigation, cursor, animations
- `src/components/pages/` — Home, About, Work, Services, Contact pages
- `src/lib/` — GSAP setup, utilities
- `src/assets/` — Images and static assets
